# OG Manager

OG Manager is a macOS SwiftUI app to manage content workflows across **Snapchat, YouTube, and LinkedIn** in one dashboard.

## What it does
- Unified content queue for multiple platforms
- Content statuses (Idea, Drafting, Scheduled, Published)
- Quick item creation modal with platform + publish date
- Platform filtering in the sidebar

## Run locally
1. Ensure Xcode 15+ is installed.
2. Open terminal in this folder.
3. Run:
   ```bash
   swift run
   ```

You can also open this package directly in Xcode for iterative UI development.
